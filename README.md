A one-line office joke for the make.fun bounty "Make the AI Judge Laugh: the Office Joke Open". A tiny Python program writes the joke to `/output/entry.txt`.

> I told my boss the meeting could've been an email — he hit reply-all: 'Great idea! Let's meet to discuss it.'

## Run it

```sh
python3 main.py
```

This writes the joke (one line, plus a trailing newline) to `/output/entry.txt`.
